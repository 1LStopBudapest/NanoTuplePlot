# --- notes -------------------------------------------------------------------
# Transitive dependencies are intentionally NOT pinned here. pip 20.3.4 honours
# Requires-Python metadata, so it resolves the correct py2.7 versions by itself
# (kiwisolver 1.1.0, pyparsing 2.4.7, cycler, python-dateutil, pytz, six).
# install_venv.sh writes the fully-resolved set to requirements.lock.txt after a
# successful install -- that file, not this one, is the reproducible artifact.
#
# subprocess32 is pulled in by matplotlib on py2 and is sdist-only, i.e. it
# compiles. CMSSW's gcc is on PATH so it normally builds fine. If it ever fails,
# matplotlib guards that import in a try/except, so this is a safe fallback:
#     pip install --no-deps matplotlib==2.2.2
#
# If the probe (probe_lxplus.sh section 7) shows CMSSW already ships a package
# here at a version we are happy with, the corresponding pin can be dropped --
# but only together with a decision about the PYTHONPATH prepend (see README).
